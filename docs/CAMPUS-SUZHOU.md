# 校园数据 · 南京大学苏州校区

## 数据来源

- 官方指南《学在苏州》（Learning at Suzhou，苏州校区党工委/管委会出品，2025 版）
  的「校区地图」「教学场地」等章节：建筑名录、地标、校门、运动场、水系与山林。
- 校区经纬度原点为**近似值** `(31.3576, 120.3770)`，取自公开地图上
  「苏州市太湖大道 1520 号」附近，非精确测绘。
- 布局为游戏化的示意还原：建筑中心点/尺寸按地图目测比例取整，道路取中线，
  不代表施工坐标。

## 数据文件

| 端 | 文件 | 说明 |
| --- | --- | --- |
| JS | `demo/js/campus-suzhou.js` | `registerCampus({...})` 注册，游戏局部坐标（米，+x 东 / +y 北） |
| C# | `unity/Assets/Scripts/Core/CampusLayout.cs → CreateSuzhou()` | 镜像同一份道路/建筑/主环线，供 Unity 与 SimHarness 使用 |

两侧保持手工同步；改任何一侧请同步另一侧并跑 `node tools/verify-demo.js`
与 `dotnet run -c Release --project tools/SimHarness`。

## 内容清单

- **道路 14 条**：太湖大道（南界）、有轨电车 2 号线、普陀山路、昆仑山路（北界）、
  九曲河路（东界）、虎丘大道、中央大道、西大道、东大道、诒微路、君毅路、
  季刚路、焕庸路、运动场跑道（400m 田径场，中心 (480,40)）。
- **建筑 38 栋**：图书馆（西/东）、教学楼（AB区）、南雍楼、行政楼、大礼堂、
  北大楼（风貌群）、科创大厦、科研综合体一~四、公共科研平台西A/西B、
  国际学术交流中心、书院群（本科生书院 1/2、硕士生书院）、仁园/勇园/知园、
  体育馆/游泳馆、大学生活动中心、各食堂与商业网点、校医院/门诊部等。
- **水系**：中心湖（椭圆）+ 九曲河（东侧南北向折线）。
- **山林**：庄里山（校内山林步道）、硕士林、西园绿带 —— 确定性生成林木。
- **地标 27 处**：巡礼模式发现半径 30~70m，含名称与一句话说明。
- **校门 5 座**：南门、西门、北门、东门、东南门。
- **主环线 ≈3.47km**：南门 → 中央大道 → 焕庸路 → 九曲河路 → 君毅路 →
  虎丘大道 → 诒微路 → 回中央大道（7 顶点闭合折线）。

## 局部坐标系

- 单位米；`+x` 向东，`+y` 向北；原点经纬度如上。
- 经纬度换算由 `LocalFrame`（JS）/ `WorldGeoMapper`（C#）完成，
  使用 `metersPerDegLat/Lon` 随纬度修正，两侧算法一致。
- 边界 `bounds` 由 initCampus 依据道路/建筑/水系外扩 30m 自动计算。
